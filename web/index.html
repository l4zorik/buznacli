Lazorikcode je open-source kódovací agent v TypeScriptu. Čte soubory, píše kódy, spouští příkazy — a každý svůj tah ti umí vrátit zpět. Režim plánování, snapshot každého souboru, žádná telemetrie.

npm i -g lazorikcode GitHub ↗
$ npm i -g lazorikcode
$ lazorik setup  # API klíč (free modely hned)
$ lazorik  # jedeš

Bezpečnost first

/undovrátí celý tah

Agent před každým zápisem zachytí původní stav souboru. Jedna šarže = jeden tah. /undo vrátí všechno, /redo to zase dopředu. Snapshoty žijí mimo tvůj projekt.

plannejdřív plán, pak kód

V režimu plan agent jen čte a navrhuje. Až plán odsouhlasíš, přepni do code. Žádné „ups, smazal jsem ti produkční SQL".

$příkazy pod dohledem

run_command prochází allowlistem. Cokoliv mimo seznam jde přes explicitní potvrzení. Citlivé soubory jsou chráněné před čtením i zápisem.

~žádná telemetrie

Klíče i session žijí lokálně v tvé konfiguraci (práva 600). Nula runtime závislostí — jen Node builtins. MIT licence.

>>>streaming odpovědi

Odpověď roste token po tokenu, ne až na konci. Ctrl+C zruší probíhající volání čistě — snapshoty pro /undo se stejně uzavřou.

◎free modely hned

Zen gateway i OpenRouter mají free modely. Zadej klíč přes lazorik setup, vyber model a jedete. Bez karty, bez trialu.

Časté otázky

Je to zdarma?
Ano — CLI je MIT a free modely fungují bez placení. Placená vrstva (gateway, Pro, firemní tier) přijde později; CLI zdarma zůstane navždy.
Kam posíláš moje data?
Nikam. Dokud si nevybereš placený model, klíče i session žijí lokálně v tvé konfiguraci. OpenCode Zen / OpenRouter dostane jen API volání, která sám odešleš.
Běží to na Windows?
Ano — primárně na něm vyvíjíme. Funguje i na macOS a Linuxu.
Jaký je rozdíl mezi plan a code režimem?
V plan má agent jen čtecí nástroje (list, read, git diff) — nemůže nic přepsat. V code má i zápis a spouštění příkazů.
Jak vyděláváte?
Později na placeném model gateway (reseller OpenRouter) a firemním tieru. CLI zůstane zdarma — to je náš open-source příslib.
